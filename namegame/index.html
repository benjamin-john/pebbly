The Name Game

A party memory game for one Game Master and a group of players.

How to play

  1. Pass the phone around. Each player secretly types a name: a celebrity, a character, anyone.
  2. The Game Master reads the whole list out loud, twice.
  3. Players take turns guessing who wrote which name. Guess right and that person joins your team.
  4. The Game Master checks off each name as it's guessed.
