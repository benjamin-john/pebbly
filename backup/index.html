Backup & restore

Pebbly keeps your host links, names and settings on this phone. A backup key (six words) gets them back if this phone’s data is cleared, or moves them to a new phone. No account needed.

Restore on this phone

Type or paste your six backup words. Anything already on this phone stays; the backup is added to it.

What’s in a backup?
  • Host and organizer links for every app (RSVP, Which Day Works?, Poll, Sign-up Sheet, Split the Bill, Shared List, Secret Santa, Live Quiz, Baby Names)
  • Which events you replied to as a guest, so you can still change your answer
  • Your names, event passwords you’ve entered, and notification settings
  • Remembered player names, Trivia question sets, game stats and settings

Not included: games in progress, and phone alerts (turn those on again on a new phone). The backup is locked with your six words before it leaves the phone, so nobody else, including Pebbly, can read it.
