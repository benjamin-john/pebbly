Install Pebbly

Add Pebbly to your home screen and it opens like an app: full screen, with its own icon.

AndroidYour phone

Chrome

  1. Open pebbly.dev in Chrome.
  2. Tap the ⋮ menu at the top right.
  3. Tap Add to Home screen, then Install.

Samsung Internet

  1. Tap the ☰ menu at the bottom right.
  2. Tap Add page to → Home screen.

Tip: long-press the Pebbly icon for shortcuts straight to RSVP, Poll and more.

iPhone and iPadYour phone

  1. Open pebbly.dev in Safari.
  2. Tap the Share button (a square with an arrow pointing up). If you don't see it, tap ⋯ first.
  3. Scroll down and tap Add to Home Screen.
  4. If you see Open as Web App, leave it on. Tap Add.

Chrome on iPhone works too: tap the Share button in the address bar, then Add to Home Screen.

ComputerYour device

  1. Open pebbly.dev in Chrome or Edge.
  2. Click the install icon at the right end of the address bar, or open the browser menu and choose Install Pebbly (in Chrome it's under Cast, save, and share).

You don't need to install it to use it: every app works in a normal browser too. Back to Pebbly
